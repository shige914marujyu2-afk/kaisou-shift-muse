# 動画③ 台本 ― データ移動と管理者メニュー

Muse版シフト表ツール 説明イラスト動画③。⑤「便利な機能」での端末間データ移動と、🔑管理者メニューの仕事。登場する回送員は架空の「回送員A〜」。メールアドレスは出さない。Muse版では配布・送信は端末内だけの疑似動作であることを正直に案内する。

音声：日本語TTS（落ち着いた女性の声）。テロップ＝ナレーション全文。

## 配信形式についてのメモ

GitHub コネクタの push は UTF-8 テキストのみ対応のため、MP4 そのものはリポジトリに入れられない。リポジトリには Base64 化した `video1.mp4.b64` 等を置き、アプリ側で読み込んで復元し、`<video controls>` でページ内再生する。
