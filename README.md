# 回送員シフト表ツール（Muse版）

Claude製ツールのコードは一切見ず・コピーせず、仕様メモ
（`~/workspace/shift-repro/spec-notes.md`、実物確認の追記を含む）と
作業リスト14項目（shift-todo）だけを正本として、ゼロから作った再現実装。

## 開き方

`index.html` をブラウザで開くだけ（ビルド不要・フレームワークなし）。
データはその端末のブラウザの localStorage にだけ保存される。

- `index.html` … 画面の土台とCSS（ダークテーマ、印刷用フォールバック）
- `app.js` … 画面・操作ロジック（①〜⑤、管理者メニュー、印刷シート生成）
- `solver.js` … 計算エンジン。検証済みPython版（solver.py/check.py/common.py）の
  計算仕様をJavaScriptに移植したもの。CP-SATの代わりに
  「週ごとの最大フロー割当て＋焼きなまし＋局所探索＋修復フェーズ」で解く。
  ブラウザとNodeの両方で動く。
- `test-solver.js` … JSソルバーをPython版と同じダミー入力で解かせ、
  解を solution 形式JSON（`solution-js.json`）に書き出す検証スクリプト。

### JSソルバーの検証（Python版 check.py による外部検証）

- 手順：`node test-solver.js 60` でダミー入力（dummy-members.json ＋
  dummy-2026-12.json ＋ conditions-dummy.json）に対する A案・B案を解き、
  solution-js.json に書き出し、検証済み Python 版で検証した。
  ```

  ./venv/bin/python check.py --members dummy-members.json \
    --input dummy-2026-12.json --conditions conditions-dummy.json \
    --solution ../shift-app/solution-js.json
  ```
- 結果：**A案・B案とも「全項目OK」、検証終了：違反合計 0 件（exit 0）**。
  JS内蔵の verifyShift でも違反 0 件。所要時間は A＋B で約122秒。
- 警告は両案とも12月26日の飛び石3件のみ（25日休→26日出→27日〜全体休の
  境界で、Python 版 CP-SAT の解でも同じ箇所に3件残った既知の限界。
  tobiishi_soft=True として扱う）。
- 解法上の要点：swap（休みの交換）だけでは日の出勤人数が固定され、
  閑散日に休みを寄せる配置に到達できない。週内で1人だけ休みを移す
  move と、満員の日を空ける2段ローテーションを仕上げ探索（hardPolish）
  に加えたことで、Python 版と同じ到達可能性を確保した。
